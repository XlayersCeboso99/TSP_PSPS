# CU-08 — Consultar actividades realizadas y pendientes

Proyecto: PSPS Academy
Sprint: 02
Responsable: Marco Antonio de Jesús Oliva Santos

## Descripción
Permitir al estudiante consultar las actividades disponibles, agrupadas por módulo y tema, distinguiendo entre Pendiente y Realizada.

## Requisitos relacionados
- RF-09
- CA-09A
- RF-08 (persistencia local)

## Reglas
- Consultar actividades no modifica el progreso.
- Abrir la vista no otorga puntos ni logros.
- Las actividades siguen siendo opcionales.
- Al seleccionar una actividad, puede iniciarse CU-02.

## Estado
Componentes preparados; integración y pruebas pendientes de verificar.
